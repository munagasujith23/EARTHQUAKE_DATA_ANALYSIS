Dataset
-------
Name: Significant Earthquake Dataset (Significant Earthquakes, 1965-2016)
Provider: U.S. Geological Survey (USGS) / National Earthquake Information Center (NEIC)
Platform: Kaggle
Link: https://www.kaggle.com/datasets/usgs/earthquake-database

Description:
Date, time, and location of all earthquakes with a reported magnitude of 5.5
or higher, recorded worldwide from 1965 to 2016. The dataset is compiled and
maintained by the USGS National Earthquake Information Center (NEIC), which
determines the location and size of significant earthquakes globally.

How to Run the Code
--------------------
1. Download the dataset from the Kaggle link above.
2. Save the downloaded file as "earth_quake.csv".
3. Place "earth_quake.csv" in the same folder as "earthquake.py" (code/).
4. Run earthquake.py.
